# Team One

Team One is a company-level attendance and employee management application built with Flutter.

It helps organizations manage employee attendance, working hours, leave requests, leave approvals, internal communication, calendars, and administrative activities from a single platform.

## 📌 About Team One

Team One is designed for companies and organizations that need a centralized system to manage employee attendance and daily workforce activities.

The application provides separate functionality for employees and administrators.

Employees can manage their attendance, check working hours, submit leave requests, communicate internally, and view their attendance information.

Administrators can manage employees, monitor attendance, review leave requests, approve or reject leaves, and manage company-level activities.
